# 📱 Vizyoner Finans Mobil (PWA)

**Vizyoner Finans Mobil**, masaüstü sürümünün tüm gelişmiş özelliklerini (Dashboard, Gelir-Gider, Portföy Takibi, Borçlar, Gelecek Simülasyonu, FIRE, Kişisel Enflasyon, Gider Projeksiyonu, AI Koç) akıllı telefonlara taşıyan, **iOS** ve **Android** uyumlu, **çevrimdışı (offline-first)** çalışan modern bir Progressive Web App (PWA) uygulamasıdır.

---

## ✨ Mobil Öne Çıkan Özellikler

- 📱 **iOS & Android Native Deneyimi:** Çeltik, Dinamik Ada ve alt çubuklar için Safe-Area uyumu (`viewport-fit=cover`).
- 🧭 **Alt Gezinme Çubuğu (Bottom Navigation Dock):** Özet, İşlemler, Portföy ve Menü arasında tek dokunuşla akıcı geçiş.
- ⚡ **Hızlı İşlem FAB (+):** Alt ortada tek dokunuşla açılan Gelir, Gider, Yatırım ekleme paneli (Bottom Sheet).
- 🔒 **%100 Çevrimdışı Çalışma (Offline-First):** Service Worker (`sw.js`) ve LocalStorage motoru sayesinde internet çekmese bile tüm işlemler kaydedilir, verileriniz hiçbir zaman kaybolmaz.
- 🌐 **GitHub Pages / Sunucusuz Mimari:** Herhangi bir backend python sunucusu gerektirmeden doğrudan GitHub Pages üzerinde ücretsiz olarak yayınlanabilir.
- 🔄 **Masaüstü ile Tam Uyum:** Masaüstü sürümündeki verileriniz (`synced_data.js`) mobil sürüme otomatik aktarılmıştır. JSON yedekleme ile iki ortam arasında anında veri alışverişi yapılabilir.
